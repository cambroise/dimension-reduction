# ICA via EM Algorithm - R Implementation

A complete implementation of Independent Component Analysis (ICA) using the Expectation-Maximization (EM) algorithm in R.

## Overview

This implementation follows the probabilistic ICA framework introduced by Attias (1999), where each source is modeled as a mixture of Gaussians. This makes the E-step tractable while allowing for flexible non-Gaussian source distributions.

## Mathematical Framework

### Model

The observed data is generated by:

```
X = A * S + ε
```

where:
- **X** ∈ ℝ^(d×n): observed data (d dimensions, n samples)
- **A** ∈ ℝ^(d×k): mixing matrix (parameter to estimate)
- **S** ∈ ℝ^(k×n): independent latent sources
- **ε**: observation noise (Gaussian)

Each source s_i is modeled as a mixture of Gaussians:

```
p(s_i) = Σ_m α_im * N(s_i | μ_im, σ²_im)
```

### Algorithm

**E-Step**: Compute posterior p(S|X,A) and responsibilities γ for mixture components

**M-Step**: Update parameters
- Mixing matrix: A ← X * E[S]^T * (E[SS^T])^(-1)
- Mixture parameters: α, μ, σ² using weighted ML estimates

## Features

- ✅ Probabilistic framework with maximum likelihood estimation
- ✅ Flexible source modeling via Gaussian mixtures
- ✅ Multiple initialization methods (PCA, random)
- ✅ Convergence monitoring via log-likelihood
- ✅ Built-in visualization functions
- ✅ Handles dimensionality reduction (d > k)
- ✅ Robust to noise

## Quick Start

### Basic Usage

```r
# Generate synthetic data
set.seed(42)
n <- 1000
S_true <- rbind(
  sin(2 * pi * seq(0, 10, length.out = n)),
  sign(sin(3 * pi * seq(0, 10, length.out = n))),
  rnorm(n)
)
A_true <- matrix(rnorm(3 * 3), 3, 3)
X <- A_true %*% S_true

# Run ICA-EM
result <- ica_em(X, n_components = 3, n_mixtures = 3, 
                 max_iter = 100, verbose = TRUE)

# View results
print(result)
plot(result, type = "convergence")
plot(result, type = "sources")
```

## Main Function

### `ica_em()`

Performs ICA using the EM algorithm.

**Arguments:**

- `X`: Data matrix (d × n) where rows are dimensions, columns are observations
- `n_components`: Number of independent components (default: d)
- `n_mixtures`: Number of Gaussian components per source (default: 3)
- `max_iter`: Maximum EM iterations (default: 100)
- `tol`: Convergence tolerance on log-likelihood (default: 1e-6)
- `noise_variance`: Observation noise variance (default: 0.1)
- `verbose`: Print iteration details (default: TRUE)
- `init_method`: Initialization method: "random" or "pca" (default: "pca")

**Returns:**

A list (class `ica_em`) containing:
- `A`: Estimated mixing matrix (d × k)
- `S`: Estimated sources (k × n)
- `W`: Unmixing matrix (pseudo-inverse of A)
- `source_params`: Mixture model parameters for each source
- `log_likelihood`: Log-likelihood at each iteration
- `converged`: Whether algorithm converged
- `n_iter`: Number of iterations performed
- `X_mean`: Mean of input data (for reconstruction)

## Algorithm Details

### Key Design Choices

1. **Mixture of Gaussians**: Each source is modeled as a mixture (default: 3 components) to approximate non-Gaussian distributions

2. **MAP Estimation**: Uses Maximum A Posteriori estimate of sources in E-step rather than full posterior integration (computationally efficient)

3. **Normalization**: Mixing matrix columns are normalized at each M-step to prevent scaling ambiguity

4. **Initialization**: 
   - `"pca"`: Uses PCA projection with small random rotation (recommended)
   - `"random"`: Random orthogonal matrix

5. **Convergence**: Monitors relative change in log-likelihood (default tolerance: 1e-6)

### Computational Complexity

- **E-step**: O(k × m × n) where k = components, m = mixtures, n = samples
- **M-step**: O(k³ + d × k × n) for matrix operations
- **Memory**: O(d × n + k × m × n) for data and responsibilities

Typical runtime: 1-2 seconds for 1000 samples, 3 components, 3 mixtures per component.

## Comparison with Other ICA Methods

| Method | Approach | Speed | Flexibility | Uncertainty |
|--------|----------|-------|-------------|-------------|
| **FastICA** | Fixed-point | ⚡⚡⚡ | ⭐⭐ | ❌ |
| **Infomax** | Gradient descent | ⚡⚡ | ⭐⭐⭐ | ❌ |
| **ICA-EM** | EM algorithm | ⚡ | ⭐⭐⭐⭐ | ✅ |

**When to use ICA-EM:**
- You need a probabilistic model
- Uncertainty quantification is important
- You want to incorporate prior knowledge
- Missing data or incomplete observations
- Integration with larger Bayesian models

**When to use alternatives:**
- Speed is critical (use FastICA)
- Simple, quick analysis needed
- Real-time processing

## Limitations

1. **Computational Cost**: Slower than FastICA due to iterative EM updates
2. **Local Optima**: Converges to local maximum (initialization matters)
3. **Identifiability**: 
   - Cannot recover source scaling
   - Cannot recover source ordering (permutation ambiguity)
4. **Gaussian Sources**: Cannot separate purely Gaussian sources
5. **Mixture Components**: Requires choosing number of mixtures per source

## Tips for Best Results

1. **Preprocessing**: Center and optionally whiten data before ICA
2. **Initialization**: PCA initialization usually works well
3. **Mixture Components**: Start with 3-5 components per source
4. **Multiple Runs**: Try several random initializations if results are poor
5. **Noise Variance**: Set appropriately based on expected noise level
6. **Convergence**: Increase `max_iter` if convergence is slow
